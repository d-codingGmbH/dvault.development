## Summary
This charter anchors the initial backlog for DConding.Data.DVault, a .NET 10 library that extends Entity Framework for Data Vault 2.x-oriented persistence.

## Scope
- Keep the default developer experience simple and convention-first.
- Track shared architectural, coding, documentation, testing, and packaging requirements in the attached guidelines document.
- Use this ticket as the central reference for implementation standards that should not be copied into every child ticket.

## Acceptance Criteria
- The central guidelines attachment is available on this ticket.
- All initial planning tickets are linked to the relevant epics, stories, tasks, milestones, and releases.
- Documentation and ticket text are written in English.

## Definition of Done
- The backlog can be used by a developer or bot without requiring additional clarification about project-wide standards.
